# COS30045 – Data Visualisation

This repository contains my exercises, labs and project work for **COS30045 – Data Visualisation** at **Swinburne University of Technology**.

---

## About the Unit

COS30045 focuses on the fundamental principles of **information visualisation** and effective visualisation design.

Throughout the unit, I will explore how data can be processed, analysed and communicated through appropriate visual representations. The unit also introduces interactive web-based data visualisation using technologies such as **D3.js**.

---

## Learning Areas

Topics covered throughout the unit include:

- Introduction to Data Visualisation
- Data Processing and Exploration
- Visualisation Design Guidelines
- Marks and Visual Channels
- Chart Types
- Data Storytelling
- Data Sources and Privacy
- D3.js
- Static Visualisations
- Interactive Web Visualisations
- Human Perception and Cognition
- Accessibility
- Usability Evaluation
- Interaction Design
- Data Visualisation Design

## Exercises and Labs

The exercises throughout the unit involve:

- Data exploration and processing
- Selecting appropriate visual attributes
- Creating charts for communication
- Identifying the target audience
- Developing a data story
- Considering data sources and privacy
- Discussing data accuracy, limitations and ethics
- Adding contextual information around visualisations

## Learning Outcomes

Through this unit, I aim to develop the ability to:

1. Critically evaluate data visualisations using visualisation design principles and an understanding of human perception.
2. Apply a structured design process when creating visualisations.
3. Develop and iterate data visualisation designs using sketches and low-fidelity prototypes.
4. Create interactive web-based data visualisations using real-world datasets.
