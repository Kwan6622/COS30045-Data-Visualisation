ABOUT THIS WEBSITE

About Us

Helping users understand appliance energy consumption through a simple and accessible website.

OUR PURPOSE

Making energy information easier to understand

The Appliance Energy Consumption Website is a small educational website designed to introduce users to the concept of energy consumption in household appliances.

The website focuses on information relevant to the Australian market and uses televisions as an example of a common household appliance.

Our goal is to present information in a clear, simple and accessible format so that users can better understand how everyday appliance usage relates to electricity consumption.

WEB DEVELOPMENT

Technologies used

This website demonstrates fundamental web development concepts using three core technologies:

  • HTML — used to structure the content.
  • CSS — used to style the website and create a consistent visual design.
  • JavaScript — used to provide interactive FAQ and Calculator functionality.
