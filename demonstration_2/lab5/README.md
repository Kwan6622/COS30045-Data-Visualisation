# Lab 5 — Comparative Data Visualisations

Lab 5 extends the appliance-energy website with D3.js charts and multiple datasets.

## Projects

- [5.1](./5.1/) — Bar chart comparing energy consumption by technology.
- [5.2](./5.2/) — Bar chart plus electricity spot-price line chart.
- [5.3](./5.3/) — Bar, line, and donut charts combining energy, price, and screen-size data.

Each project is a self-contained web page. Open `index.html` in a local web server so that D3 can load the CSV files.
