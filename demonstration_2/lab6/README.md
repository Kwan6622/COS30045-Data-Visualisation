# Lab 6 — Interactive TV Energy Visualisations

Lab 6 uses D3.js and the TV energy dataset to build increasingly interactive visualisations.

## Projects

- [6.1](./6.1/) — TV energy-consumption histogram.
- [6.2](./6.2/) — Filterable histogram by screen technology and size.
- [6.3](./6.3/) — Filterable histogram with a TV energy scatterplot.
- [6.4](./6.4/) — Extended histogram and scatterplot with shared interactions and tooltips.

Each project includes its CSV data, JavaScript modules, and (where supplied) the KNIME workflow used during data preparation. Open `index.html` through a local web server.
